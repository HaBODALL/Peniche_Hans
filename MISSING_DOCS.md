# Documents manquants, à télécharger manuellement, ou références vagues

Ce document recense les fichiers qui n'ont pas pu être téléchargés automatiquement (ex: protection Cloudflare), les documents en attente d'être déposés, ou les références "vagues" qui étaient présentes sous forme de coquilles vides.

L'objectif (en cette année 2026) est de s'assurer que ces documents soient correctement sourcés avec les versions les plus récentes.
