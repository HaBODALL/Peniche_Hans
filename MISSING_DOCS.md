# Documents manquants ou placeholders (Coquilles Vides)

Ce document recense les fichiers listés dans les différentes bibliographies du projet qui sont actuellement des "coquilles vides" (fichiers PDF factices ou de très petite taille) ou des documents manquants devant être récupérés ultérieurement.

Ils doivent être trouvés, téléchargés et remplacés par leur version complète et valide pour garantir que la documentation est exploitable hors ligne, conformément aux directives du projet.

## Liens potentiels pour la récupération
Voici quelques liens qui pourraient servir à télécharger les versions complètes de ces documents :
- **ES-TRIN (Standard Européen des Prescriptions Techniques des Bateaux)** : Disponible sur le site du CESNI (Comité Européen pour l'Élaboration de Standards dans le Domaine de la Navigation Intérieure) : `https://www.cesni.eu/fr/es-trin/`
- **CEVNI (Code Européen des Voies de la Navigation Intérieure)** : Disponible sur le site de la CEE-ONU (Commission Économique pour l'Europe des Nations Unies) : `https://unece.org/transport/watermark/cevni-european-code-inland-waterways`
- **Règlement UNECE R100** : Disponible également sur le site de la CEE-ONU concernant la sécurité des véhicules électriques : `https://unece.org/transport/standards/transport/vehicle-regulations`
- **Réglementation VNF** : Souvent consultable sur le site officiel de Voies Navigables de France (VNF), section réglementation et environnement : `https://www.vnf.fr/vnf/`
- **Tutoriel Low-Tech Lab Bokashi** : Disponible sur le wiki du Low-Tech Lab : `https://wiki.lowtechlab.org/`
