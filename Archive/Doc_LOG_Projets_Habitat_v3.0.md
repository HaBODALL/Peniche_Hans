## 🔧 SPÉCIFICATIONS HABITAT (Contraintes PMR)

### Accessibilité obligatoire
- Largeur circulation minimale : 90 cm
- Espace de giration fauteuil : 150 cm diameter
- Pas de seuils (ou rampes < 5%)
- Barres d'appui : WC, douche, accès
- Revêtement sol : antidérapant R11 minimum

### Isolation cible
- Objectif : confort hiver sans chauffage lourd
- Solution pressentie : laine bois/chanvre (hygroscopique, adapté milieu humide)
- Alternative : liège projeté (décision après visite)
- Points thermiques critiques : fond de cale, panneaux latéraux, pont

### Chauffage Phase 1
- Poêle à bois provisoire (solution économique)
- PAC réversible en Phase 2 (après CDI)
